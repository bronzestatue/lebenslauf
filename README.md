📄 Interactive CV Portfolio | Constantin Sinowski
This repository contains the source code and assets for my personal interactive portfolio and digital resume, accessible at sinowski.de. The site is designed to showcase my professional background, technical expertise in Data/IA, and provide a seamless way for recruiters and partners to connect with me.

👤 About Me
I am a Bachelor of Engineering specializing in Data Analysis, Automation, and Digital Processes. With extensive experience in Business Intelligence & Data Analytics, I bridge the gap between technical engineering and analytical business solutions.

Focus: Data-driven decision-making, AI integration, and process automation.

Goal: Developing scalable, automated solutions for complex business environments.

🚀 Key Features of the Website
Interactive UI: A 50% focus-layout optimized for readability and professional aesthetics.

Glassmorphism Sidebar: A modern, blurred sidebar providing constant access to contact details and Stammdaten.

Floating Navigation: Desktop-optimized quick links for seamless section jumping.

Calendly Integration: Direct booking system for professional meetings and interviews.

Responsive Design: Fully functional on mobile and tablet devices.

Print Optimized: Special CSS rules to ensure the web view converts perfectly into a professional PDF format.

🛠 Technical Stack
The project is built with a focus on Performance (Lighthouse 100) and Clean Code:

HTML5: Semantic structure for SEO and accessibility.

CSS3 (Advanced):

CSS Variables: Centralized theme control.

Flexbox & Grid: Used for the 75/25 split-header system and responsive layouts.

Media Queries: Tailored break-points for various screen sizes.

FontAwesome: Consistent iconography across the entire profile.

Google Fonts: Clean, modern typography (Inter/Roboto/Calibri stack).

📐 Architectural Logic (plan.md)
The layout follows a strict professional hierarchy:

75/25 Header Grid: All entries (Experience, Education, Certs) use a fixed grid where 75% is reserved for the title/role and 25% for the right-aligned dates.

Fokus-Zone: The main content is capped at 800px to ensure line lengths remain optimal for reading long-form professional experience.
